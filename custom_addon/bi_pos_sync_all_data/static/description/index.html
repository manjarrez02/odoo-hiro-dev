Auto Sync POS All Data Odoo App

Automatic POS All Data Sync in All Session

Auto Sync POS All Data without Restart Session

Automatic POS All Data Sync odoo app helps users to automatically sync all pos data like new added customers, updated customers, new added products, and product details like name, price, and stock to all running point of sale sessions without refresh or reload.

After creating or updating new customers or products in the point of sale backend, users need to restart and reload the point of sale session every time and its headache. But now using this odoo app users can forget to restart the pos session as all point of sale data will automatically sync to all pos session.While the user creates a new customer or updates an existing customer, creates a new product or updates an existing product details like name, price, and stock then it will automatically sync and update to all point of sale sessions, and user no need to refresh page or restart pos session.

Features

Auto Sync POS All Data

User cxan automatically sync all product data without restart or refresh pos session,

Deny POS Order Quantity

User can set quantity to deny pos order after specific quantity.

Auto Sync Customer Data

When user create new customer or update existing customer it will automatically sync.

Auto Sync Product Data

When user create new product or update existing product it will automatically sync.
