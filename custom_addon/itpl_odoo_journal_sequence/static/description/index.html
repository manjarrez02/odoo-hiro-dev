Features

Newer versions after odoo13 does not allow users to create/edit sequence for journals. Using this module you can configur and customize sequence from journals as per your requirement.

You can set sequence of your choice for Sales journal for Entry/Refund sequence and customize it as per your need.

You can set sequence of your choice for Purchase journal for Entry/Refund sequence and customize it as per your need.

You can set sequence of your choice for Bank/Cash journal and customize it as per your need.

You can set sequence of your choice for Miscellaneous journal and customize it as per your need.

Set Refund/Credit Note Sequence for Sales Journal

To set/customize this go to, Invoicing/Accounting > Configuration > Journals , here select Sales journal for which you want to set sequence and check in Sequence tab as shown in below image:

in this click on Credit Notes Entry Sequence and modify it as per your requirement

modified sequence in Refund/Credit Note Entry

Set Entry/Invoice Sequence for Purchase Journal

To set/customize this go to, Invoicing/Accounting > Configuration > Journals , here select Purchase journal for which you want to set sequence and check in Sequence tab as shown in below image:

in this click on Entry Sequence and modify it as per your requirement

modified sequence in Bill
