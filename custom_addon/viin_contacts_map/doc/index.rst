Installation 
============

* Navigate to **Apps**.
* Search with keyword *viin_contacts_map*.
* Press **Install**.

Instruction
===========

**Instruction video:** `Contacts Map <https://youtu.be/fIpDVd55AJw>`_

**1. Locate the geographical location of the contact**

*  Navigate to the Contacts app > Select the contact to locate > Press **refresh** at the **Partner Assignment** tab to locate the geographical location on the map by the contact's address.

.. image:: dinh-vi-lien-he.en.jpg
   :alt: Locating contacts by address
   :width: 1100
   :height: 500

**2. View contacts in a map view**

* Access the Contacts app > select the Viin map view.

   :alt: View contact in map form
