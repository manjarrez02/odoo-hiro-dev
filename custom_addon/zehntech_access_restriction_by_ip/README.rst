Access Restriction by IP 
================================================================

The Access Restriction by IP app restricts users from accessing Odoo based on their IP addresses, enhancing security by controlling and monitoring login attempts through IP-based restrictions.


**Table of contents**
 
.. contents::
   :local:
 
**Key Features**
================================================================

- **Restrict User by IP**: Limit access to the system by restricting specific users based on their IP addresses.
- **Multiple IP Address Support**: Allows adding and managing multiple IP addresses for specific users.
- **Unauthorized Access Notifications**: Notify administrators of unauthorized access attempts .
- **Real-Time Logs of Login Attempts**:   Monitor Failed login attempts in real-time.
- **Dynamic IP Handling**: Modify IP addresses dynamically to the users and user can login from any location in that range .

**Summary**
================================================================

The Access Restriction by IP Odoo app allows administrators to define allowed and blocked IP ranges, enhancing system security by controlling user access based on their location.


**Installation**
================================================================

1. Download the module from the Odoo App Store or clone the repository.
2. Place the module in your Odoo addons directory.
3. Update your Odoo instance to include the new module.
4. Install the module through the Odoo interface.

**How to use this module:**
================================================================

1. Navigate to the Access restriction by IP App in your Odoo dashboard.
2. **Add Ip address**: In the user settings, add authorized IP addresses for each user.
3. **Monitor Login Attempts**: Go to the logs section to view real-time data on Failed login attempts, including any blocked due to unauthorized IP addresses.
4. **Unauthorized Access Notifications**: Receive notifications through mail for any login attempt made from an unauthorized IP address .
